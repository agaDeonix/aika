# Айка

Локальный голосовой помощник для Android. Айка распознаёт короткие команды на
устройстве и выполняет системные действия без отправки аудио в сеть.

## Возможности

- локальное распознавание русской речи через Vosk;
- команды Back, Home, пауза, воспроизведение и свайп;
- отдельные команды для YouTube;
- фоновое прослушивание через microphone foreground service;
- интеграция с ролью цифрового ассистента;
- управление через Accessibility Service;
- плитка быстрых настроек для включения и паузы;
- адаптивный интерфейс на Jetpack Compose с MVI-архитектурой.

Интерфейс по умолчанию английский; русский включается для русской локали устройства.
Голосовые команды пока остаются русскими, поскольку в APK встроена русская модель Vosk.

## Команды

| Контекст | Фраза | Действие |
| --- | --- | --- |
| Любое приложение | «Айка, назад» | Назад |
| Любое приложение | «Айка, домой» или «Айка, закрой» | Домой |
| YouTube | «Айка, дальше» | Следующий Shorts |
| YouTube | «Айка, стоп» | Пауза |
| YouTube | «Айка, продолжи» | Продолжить |

## Требования

- Android 12 (API 31) или новее;
- JDK 17;
- Android SDK 36.

Проект уже содержит `vosk-model-small-ru-0.22` в
`app/src/main/assets/model`, поэтому после клонирования модель отдельно
скачивать не нужно.

## Сборка

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Настройка на устройстве

1. Установите APK и откройте Айку.
2. Разрешите доступ к микрофону.
3. Выберите Айку цифровым ассистентом.
4. Включите сервис «Айка — управление экраном» в специальных возможностях.
5. Запустите прослушивание в приложении.
6. При желании добавьте плитку «Айка» в быстрые настройки.

Некоторые прошивки дополнительно требуют снять ограничения фоновой работы и
энергосбережения для приложения.

## Архитектура

- `ui/` — MVI-контракт, reducer и store;
- `audio/` — установка модели и локальное распознавание;
- `actions/` — разбор и выполнение команд;
- `voice/` — Android VoiceInteractionService;
- `MainActivity.kt` — Compose UI.

## Приватность

Аудио обрабатывается локально и не сохраняется. Приложение не использует сеть.
Диагностический журнал хранит только последние 100 текстовых системных событий.

## Ограничения

- постоянно активный микрофон отображается системным индикатором Android;
- распознавание при выключенном или заблокированном экране отключается;
- выполнение жестов требует явно включённого Accessibility Service.
